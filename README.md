
# Console-Based To-Do List Application

# Objective
This project is a simple console-based To-Do List Manager built using Python.  
It allows users to add, view, and remove tasks with persistent storage using file handling.

# Features
- Add new tasks
- View all tasks
- Remove tasks
- Persistent storage using text file
- Error handling for invalid inputs

# Technologies Used
- Python 3.14.3
- File Handling
- Lists
- String Manipulation

# Project Structure
todo.py     → Main Python application  
tasks.txt   → Stores tasks persistently
